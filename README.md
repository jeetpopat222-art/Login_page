# 🔐 Flask Login App

> A minimal, no-nonsense authentication web app built with Python and Flask.

---

> ⚠️ **Transparency Notice**
> All HTML templates in this project were generated by an LLM (Large Language Model).
> The Python/Flask backend logic — routing, form handling, authentication — was written entirely by the developer.

---

## 📌 What Is This?

This is a lightweight Flask web application that demonstrates a basic login flow. It has a home page, a login form, and conditional routing based on whether the user's credentials are correct.

No database. No sessions. No middleware. Just Flask doing Flask things.

---


---

## ⚙️ How It Works

### Routes

| Route     | Method(s)   | Description                                           |
|-----------|-------------|-------------------------------------------------------|
| `/`       | GET         | Renders the home page (`index.html`)                  |
| `/login`  | GET         | Renders the login form (`login.html`)                 |
| `/login`  | POST        | Validates credentials and routes accordingly          |

### Authentication Logic

When a `POST` request hits `/login`, the app reads the `username` and `password` fields from the form:

- ✅ If `username == "admin"` and `password == "1234"` → renders `thankyou.html`
- ❌ Otherwise → renders `no_auth.html`

It's stateless. No tokens, no sessions — purely request-level logic.

## 🛡️ Security Notice

This project is a **learning exercise / prototype**. It is **NOT** production-ready. Here's why:

| Issue | Risk | Fix Before Production |
|---|---|---|
| Hardcoded credentials | Anyone who reads the code knows the password | Use a database with hashed passwords |
| No password hashing | Plaintext comparison | Use `bcrypt` or `werkzeug.security` |
| No session management | User state is lost after response | Use `flask-login` or JWT |
| Debug mode is ON | Exposes stack traces and the interactive debugger | Set `debug=False` in production |
| No CSRF protection | Forms are vulnerable to cross-site attacks | Use `flask-wtf` |

**Do not deploy this to a public server as-is.**

## 📚 Flask Concepts Demonstrated

- **`@app.route()`** — Registering URL routes with the app
- **`methods=["GET", "POST"]`** — Handling multiple HTTP methods on one route
- **`request.method`** — Checking the type of incoming request
- **`request.form.get()`** — Reading form fields from a POST body
- **`render_template()`** — Rendering Jinja2 HTML templates
- **Conditional routing** — Returning different responses based on business logic
